# Customized Translucence CSS for GitHub Pages

This repository layout is prepared so GitHub Pages can serve the theme at:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/Themes/Translucence/css/source.css`

## Publish it

1. Upload the contents of this folder to the root of a GitHub repository, preserving the `Themes/Translucence/css/source.css` path.
2. In that repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select branch `main` and folder `/(root)`, then click **Save**.
4. After Pages finishes publishing, open the URL above with your own GitHub username and repository name.
5. Paste that URL into Vencord → Settings → Themes → Online Themes.

The CSS uses the supplied Discord CDN image URL. If Discord's image link expires or becomes unavailable, replace it with a stable direct image URL.
